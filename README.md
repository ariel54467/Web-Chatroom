# Software Studio 2025 Spring  
## Midterm_Project_112006269

This **Chatroom Application** enables users to sign up, sign in (via Google or email), and participate in private chatrooms. Users can create groups, send text messages, upload images and videos, and manage their profiles. The app provides a real-time messaging experience using **Firebase** for backend services, including authentication, database, and hosting.

---

## How to Use

1. **Homepage**:
   - When you first open the app, you will be greeted with a homepage featuring **3D CSS animations**.
   - To get started, click the **Get Started** button.

2. **Sign Up/In**:
   - Users can **sign in** using **Google** or **email/password**.
   - If you don’t have an account, sign up first, and then proceed to sign in.

3. **Profile Editing**:
   - After signing in, you will be directed to the **chatroom**. You can edit your profile by clicking on the **Profile**.
   - You will need to have other users signed in as well since the group creation will be based on the people who have signed in.

4. **Chatroom**:
   - On the left, you’ll see a list of available chatrooms. Click to select one.
   - On the right, you will see the **chat preview** where you can interact with messages.
   - The chat input field allows you to **send text messages**, attach **images**, and **send videos**. 
     - **Images and videos must be under 500KB** to be uploaded.
   - You can **sign out** at any time by clicking the **Sign Out** button.

## To Setup

1. **Clone the Repository**:
   - Ensure that you have **Git** installed. Clone or fork the repository from GitLab.
   - If you don't have Git, you can download it from [here](https://git-scm.com/).

2. **Install Node.js**:
   - Make sure **Node.js** is installed. If not, you can download it from [Node.js Official Website](https://nodejs.org/).

3. **Install Dependencies**:
   - Navigate to the correct project directory and run:
   ```bash
   npm install
   npm install react-router-dom
   npm run build
   npm run dev
